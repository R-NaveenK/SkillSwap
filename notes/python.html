1. Data Structures & List Comprehensions

Python provides versatile built-in data structures: Lists (ordered, mutable), Tuples (immutable), Dictionaries (key-value maps), and Sets (unique values). List comprehensions provide clean syntax for filtering and transforming sequences.

data_structures.py 
skills = ["Python", "React", "Node", "Docker", "Java"]

# List comprehension filtering tech skills with length > 4
advanced_skills = [s.upper() for s in skills if len(s) > 4]
print("Filtered Skills:", advanced_skills)

# Dictionary comprehension mapping skill to point value
skill_points = {skill: 30 for skill in skills}
print("Point Mapping:", skill_points)

2. Object-Oriented Python: Classes & Dunder Methods

Python supports full OOP with class inheritance, encapsulation, polymorphism, and magic (dunder) methods such as __init__, __str__, and __repr__.

oop_swapper.py 
class SkillSwapper:
    def __init__(self, username, points=120):
        self.username = username
        self.points = points

    def reward(self, delta):
        self.points += delta
        return f"{self.username} earned +{delta} Pts. Balance: {self.points}"

    def __str__(self):
        return f"User({self.username}, Points={self.points})"

user = SkillSwapper("Naveen", 120)
print(user.reward(30))

3. Decorators & Generator Functions

Decorators modify or extend function behavior dynamically without altering the source code. Generators yield values lazily, allowing efficient memory handling for large datasets.

decorators_generators.py 
import time

def timer_decorator(func):
    def wrapper(*args, **kwargs):
        start = time.time()
        result = func(*args, **kwargs)
        print(f"Executed {func.__name__} in {time.time() - start:.4f}s")
        return result
    return wrapper

@timer_decorator
def generate_course_stream(count=1000):
    for i in range(count):
        yield f"Course Note #{i}"

for note in generate_course_stream(3):
    print(note)
