1. JVM Architecture & Memory Management

Java code compiles into intermediate bytecode (.class) executed by the Java Virtual Machine (JVM). JVM memory is divided into Heap, Stack, Metaspace, and Program Counter registers.

  • Heap Memory: Stores objects, arrays, and instance variables managed by Automatic Garbage Collection (G1GC / ZGC).
  • Stack Memory: Holds primitive local variables and method call frames.
CoursePartner.java 
public class CoursePartner {
    private String name;
    private int points;

    public CoursePartner(String name, int points) {
        this.name = name;
        this.points = points;
    }

    public synchronized void rewardPoints(int delta) {
        this.points += delta;
    }

    public int getPoints() {
        return points;
    }
}

2. Streams API & Functional Operations

Java 8+ Streams allow functional-style operations (filter, map, reduce) over collections without explicit loop mutations.

StreamFilterDemo.java 
import java.util.List;
import java.util.stream.Collectors;

public class StreamDemo {
    public static void main(String[] args) {
        List<String> courses = List.of("Java", "Python", "React", "Docker", "Node");

        List<String> filtered = courses.stream()
            .filter(c -> c.length() > 4)
            .map(String::toUpperCase)
            .collect(Collectors.toList());

        System.out.println("Filtered Courses: " + filtered);
    }
}
