1. Pointers & Raw Memory Addresses

In C, a pointer variable holds the raw hexadecimal memory address of another variable. The address-of operator (&) extracts a memory location, while the dereference operator (*) accesses or mutates the value stored at that address.

pointers_demo.c 
#include <stdio.h>

void updatePoints(int *pointsPtr, int bonus) {
    *pointsPtr += bonus; // Dereference and add bonus
}

int main() {
    int userPoints = 120;
    printf("Initial Points: %d\n", userPoints);
    
    updatePoints(&userPoints, 30);
    printf("Updated Points: %d\n", userPoints); // 150
    return 0;
}

2. Dynamic Memory Allocation (Heap vs Stack)

Use malloc() or calloc() to allocate contiguous memory blocks on the heap at runtime, and always release memory using free() to prevent memory leaks.

dynamic_mem.c 
#include <stdio.h>
#include <stdlib.h>

int main() {
    int n = 5;
    int *arr = (int*) malloc(n * sizeof(int));

    if (arr == NULL) {
        printf("Memory allocation failed!\n");
        return 1;
    }

    for (int i = 0; i < n; i++) {
        arr[i] = (i + 1) * 10;
    }

    free(arr); // Prevent memory leak
    arr = NULL; // Dangling pointer safety
    return 0;
}
