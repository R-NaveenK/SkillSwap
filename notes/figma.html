Figma UI/UX Design – Auto-Layout & Design Systems

Master Design Tokens, Responsive Auto-Layout 5.0, Component Variants & Prototyping

1. Design Tokens & Color Systems

Design tokens define raw design choices (colors, spacing, typography, shadows) as centralized variables. This allows design systems to support dynamic dark/light themes and multi-platform component export effortlessly.

design-tokens.json 
{
  "color": {
    "primary": { "value": "#d6b77c" },
    "background": {
      "dark": { "value": "#0f172a" },
      "light": { "value": "#f4efe6" }
    }
  },
  "spacing": { "md": "16px", "lg": "24px" }
}

2. Auto-Layout 5.0 & Responsive Constraints

Figma's Auto-Layout creates responsive frames that adapt automatically to content length and viewport resizing. Use Fill Container for fluid widths and Hug Contents for auto-sizing cards.
