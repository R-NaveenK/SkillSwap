1. Machine Learning Pipeline & Paradigms

Machine Learning enables systems to learn from data patterns without being explicitly programmed.

  • Supervised Learning: Training models on labeled datasets (e.g. Linear Regression, Random Forest).
  • Unsupervised Learning: Finding hidden structures in unlabeled data (e.g. K-Means Clustering, PCA).
  • Reinforcement Learning: Agent learning optimal decision policies via rewards and penalties.

def calculate_ai_point_value(complexity_score, instructor_rating, category):
    base_points = 15
    
    # Complexity Weighting
    base_points += complexity_score * 4
    
    # Rating Weighting
    if instructor_rating >= 4.8:
        base_points += 10
    elif instructor_rating >= 4.5:
        base_points += 5
        
    return int(base_points)
