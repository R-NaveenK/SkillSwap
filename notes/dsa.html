1. Big-O Complexity Analysis

Big-O notation quantifies algorithm performance as input size N scales towards infinity.

  • O(1) Constant: Direct array lookup or hash map key fetch.
  • O(log N) Logarithmic: Binary search on sorted data.
  • O(N) Linear: Single pass traversal over array elements.
  • O(N log N) Linearithmic: Efficient sorting algorithms (MergeSort, QuickSort).
  • O(N²) Quadratic: Nested loops (BubbleSort, InsertionSort).
binary_search.js 
function binarySearch(arr, target) {
    let left = 0;
    let right = arr.length - 1;

    while (left <= right) {
        let mid = Math.floor((left + right) / 2);
        if (arr[mid] === target) return mid;
        if (arr[mid] < target) left = mid + 1;
        else right = mid - 1;
    }
    return -1; // Target not found
}

console.log(binarySearch([10, 20, 30, 40, 50], 40)); // Index 3

2. Dynamic Programming & Memoization

Dynamic Programming solves complex problems by breaking them down into overlapping subproblems, storing solved results in a lookup table (memoization or tabulation) to prevent redundant calculations.

fibonacci_dp.js 
// Dynamic Programming Fibonacci O(N) Time, O(1) Space
function fibonacci(n) {
    if (n <= 1) return n;
    let prev = 0, curr = 1;
    for (let i = 2; i <= n; i++) {
        let temp = prev + curr;
        prev = curr;
        curr = temp;
    }
    return curr;
}

console.log("Fibonacci(50):", fibonacci(50));

3. Tree & Graph Traversal (BFS vs DFS)

Breadth-First Search (BFS) uses a Queue to explore graph nodes level by level (ideal for shortest paths). Depth-First Search (DFS) uses a Stack or Recursion to explore paths to maximum depth.
