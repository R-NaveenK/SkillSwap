1. OWASP Top 10 Web Vulnerabilities

Web security focuses on preventing unauthorized access, data breaches, and systemic exploits.

  • Injection (SQLi / NoSQLi): Malicious input alters query logic. Mitigated by parameterized queries and ORMs.
  • Cross-Site Scripting (XSS): Malicious script injection into rendered HTML. Mitigated by context-aware escaping & CSP headers.
  • Broken Authentication: Weak session cookies or unhashed passwords. Mitigated by Bcrypt hashing & JWT expiration.
secure_password.js 
const bcrypt = require('bcrypt');

async function hashUserPassword(plainPassword) {
    const saltRounds = 12;
    const hashedPassword = await bcrypt.hash(plainPassword, saltRounds);
    return hashedPassword; // Secure salted hash
}

async function verifyLogin(inputPassword, storedHash) {
    return await bcrypt.compare(inputPassword, storedHash);
}

2. Cryptography: Hashing vs Encryption

Hashing (SHA-256, Bcrypt) is one-way deterministic mathematical transformation used for passwords and integrity checks. Encryption (AES-256) is two-way reversible mathematical transformation requiring secret keys.
