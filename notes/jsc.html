1. Async JS, Event Loop & Promises

JavaScript executes asynchronously on a single-threaded runtime using an Event Loop. Non-blocking operations (HTTP requests, timers, disk I/O) offload tasks to web APIs, placing callbacks into Microtask and Macrotask queues.

  • Microtask Queue: Holds resolved Promise callbacks (.then(), async/await) and has higher execution priority.
  • Macrotask Queue: Holds setTimeout, setInterval, and DOM event listeners.
async_mastery.js 
async function fetchSkillData() {
    try {
        console.log("1. Request Initiated");
        const response = await fetch("http://localhost:3000/api/skills");
        const data = await response.json();
        console.log("2. Skill Swap Data Loaded:", data);
        return data;
    } catch (error) {
        console.error("Failed to load skills:", error);
    }
}

// Chaining async flows with error boundary handling
fetchSkillData().then(skills => console.log("3. UI Sync Completed"));

2. Closures & Lexical Scope Chain

A closure is a function bundled together with references to its surrounding lexical environment. Closures allow inner functions to access variables from an outer scope even after the outer function has returned.

closures.js 
function createPointsWallet(initialPoints = 100) {
    let points = initialPoints; // Private state encapsulated in closure

    return {
        addPoints(amount) {
            points += amount;
            return points;
        },
        spendPoints(amount) {
            if (amount > points) throw new Error("Insufficient Points Balance");
            points -= amount;
            return points;
        },
        getBalance: () => points
    };
}

const userWallet = createPointsWallet(120);
console.log(userWallet.addPoints(30)); // 150 Points

3. DOM Event Delegation & Performance Optimization

Event delegation leverages event bubbling to handle events at a common parent container rather than attaching separate event listeners to dozens of child elements. This saves memory and handles dynamically added elements seamlessly.

event_delegation.js 
// Efficient container listener using Event Delegation
document.getElementById("coursesContainer").addEventListener("click", (e) => {
    const card = e.target.closest(".course-card");
    if (card) {
        const courseId = card.dataset.id;
        console.log("Swapping course:", courseId);
    }
});

4. ES6+ Modules, Destructuring & Rest/Spread

Modern JavaScript uses ES6 module syntax (import / export) for code encapsulation. Object and array destructuring streamlines parameter extraction and state updates.
