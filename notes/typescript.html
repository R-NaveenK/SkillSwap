1. Static Type System & Annotations

TypeScript adds static typing to JavaScript, detecting type errors at compile-time before code reaches production environments.

types.ts 
interface SwapperUser {
    id: string;
    username: string;
    points: number;
    role?: 'Learner' | 'Mentor' | 'Admin'; // Union literal type
}

function processPointBonus(user: SwapperUser, delta: number): SwapperUser {
    return {
        ...user,
        points: user.points + delta
    };
}

const activeUser: SwapperUser = { id: 'u1', username: 'Naveen', points: 120 };
console.log(processPointBonus(activeUser, 30));

2. Generic Functions & Interfaces

Generics allow you to write reusable, type-safe components that operate over a variety of types rather than a single fixed type.

generics.ts 
interface APIResponse<T> {
    status: number;
    data: T;
    timestamp: string;
}

// Reusable generic fetch wrapper preserving exact return types
async function fetchAPI<T>(url: string): Promise<APIResponse<T>> {
    const res = await fetch(url);
    const data: T = await res.json();
    return { status: res.status, data, timestamp: new Date().toISOString() };
}

3. Built-In Utility Types

TypeScript provides powerful built-in utility types to transform existing types: Partial<T>, Readonly<T>, Pick<T, K>, and Record<K, T>.
