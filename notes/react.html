1. Virtual DOM & Reconciliation

React uses an in-memory Virtual DOM tree representation. When component state changes, React constructs a new Virtual DOM tree, performs efficient diffing against the previous tree using the Fiber algorithm, and updates only changed DOM nodes.

  • Declarative UI: You define how the UI should look for a given state, and React handles DOM updates.
  • Batching: Multiple state updates inside event handlers are automatically batched to minimize re-renders.
CourseCounter.jsx 
import React, { useState } from 'react';

export function CourseCounter({ initialPoints = 120 }) {
    const [points, setPoints] = useState(initialPoints);

    const unlockCourse = () => {
        setPoints(prev => Math.max(0, prev - 20));
    };

    return (
        <div className="wallet-card">
            <h3>Points Wallet: {points} Pts</h3>
            <button onClick={unlockCourse}>Unlock Course (-20 Pts)</button>
        </div>
    );
}

2. Side Effects & Lifecycle with useEffect

The useEffect hook lets you execute side effects such as fetching backend API data, subscribing to global events, or updating page titles after rendering.

UseFetchCourses.jsx 
import React, { useState, useEffect } from 'react';

export function CourseList() {
    const [courses, setCourses] = useState([]);
    const [loading, setLoading] = useState(true);

    useEffect(() => {
        let isMounted = true;

        async function loadCourses() {
            try {
                const res = await fetch('/api/courses');
                const data = await res.json();
                if (isMounted) setCourses(data);
            } finally {
                if (isMounted) setLoading(false);
            }
        }

        loadCourses();
        return () => { isMounted = false; }; // Cleanup subscription
    }, []); // Empty dependency array runs once on mount

    if (loading) return <p>Loading Skill Swap Courses...</p>;
    return <div>{courses.length} Courses Available</div>;
}

3. Global State Management with Context API

React's Context API passes state down the component tree without manually threading props (prop drilling) at every level.

ThemeContext.jsx 
import React, { createContext, useContext, useState } from 'react';

const ThemeContext = createContext();

export function ThemeProvider({ children }) {
    const [theme, setTheme] = useState('dark');
    const toggleTheme = () => setTheme(prev => prev === 'dark' ? 'light' : 'dark');

    return (
        <ThemeContext.Provider value={{ theme, toggleTheme }}>
            {children}
        </ThemeContext.Provider>
    );
}

export const useTheme = () => useContext(ThemeContext);

4. Performance Optimization: useMemo & React.memo

Prevent expensive calculations and unnecessary child re-renders by wrapping heavy functions in useMemo and components in React.memo.
