MongoDB & NoSQL – Document Databases & Aggregation

Master BSON Document Storage, Indexing Strategies, Aggregation Pipelines & Mongoose ODM

1. Document Data Modeling vs Relational Tables

MongoDB stores data as flexible, schema-less BSON (Binary JSON) documents. Related data can be embedded within a single document or referenced via ObjectId pointers.

UserSchema.js 
const mongoose = require('mongoose');

const UserSchema = new mongoose.Schema({
    username: { type: String, required: true, unique: true },
    points: { type: Number, default: 120 },
    unlockedCourses: [{ type: String }],
    pinnedItems: [{
        id: String,
        title: String,
        link: String
    }],
    createdAt: { type: Date, default: Date.now }
});

module.exports = mongoose.model('User', UserSchema);

2. Aggregation Pipeline Engine

MongoDB Aggregation Framework transforms data through multi-stage pipelines ($match, $group, $project, $sort, $lookup).

aggregation.js 
// Calculate total points earned per skill category
db.skills.aggregate([
    { $match: { category: "Tech" } },
    { $group: { _id: "$shareType", totalPoints: { $sum: "$pointsReward" } } },
    { $sort: { totalPoints: -1 } }
]);
