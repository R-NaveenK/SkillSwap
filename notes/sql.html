1. Relational Joins & Aggregations

SQL relational databases manage structured data organized in tables linked by Primary Key (PK) and Foreign Key (FK) constraints.

queries.sql 
-- Query active users and their total unlocked courses
SELECT 
    u.user_id,
    u.username,
    u.points_balance,
    COUNT(c.course_id) AS total_unlocked_courses
FROM users u
LEFT JOIN user_courses c ON u.user_id = c.user_id
GROUP BY u.user_id, u.username, u.points_balance
HAVING u.points_balance >= 100
ORDER BY u.points_balance DESC;

2. ACID Transactions & Database Indexing

Database transactions ensure Atomicity, Consistency, Isolation, and Durability (ACID). Indexes (B-Trees) speed up read operations at the cost of slight write overhead.
